# Практическая работа №1

## Ответы на вопросы
1. **Чем su отличается от sudo?**
   - su (switch user) переключает сессию на другого пользователя (по умолчанию root) и требует пароль этого пользователя.
   - sudo (superuser do) выполняет команду с правами администратора, запрашивая пароль текущего пользователя.

2. **Почему root заблокирован по умолчанию в Ubuntu?**
   - Для безопасности: чтобы предотвратить случайное повреждение системы и защитить от несанкционированного доступа.

## Права доступа (/srv/shared)
- Каталог /srv/shared принадлежит root:developers с правами 775.
- Файл, созданный student2, может быть удален основным пользователем, так как удаление зависит от прав на родительскую папку.
